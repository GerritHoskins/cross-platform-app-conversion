## What NS07 is

NS07 executes the acceptance checklist `migration/plans/rn07-android-acceptance-checklist.md` (cases A01–G09, written target-neutrally for slice 1) against the committed NativeScript slice (NS01–NS06) on the Android emulator, to the same evidence standard as RN07, plus native lifecycle and modal cancellation (plan row NS07). The checklist is the case specification and stays read-only; the "Target mapping" below translates its React Native specifics. NS07 is mostly evidence: product changes are allowed only as minimal target-only fixes for cases that FAIL, under the fix policy.

## Phases and sessions

Each phase is a fresh Hermes session with its own run directory, checkpoint `migration/handoffs/NS07-checkpoint-<phase>.md` and `result.json`; retries never overwrite evidence (new suffixed run-id).

1. **A — candidate and software gates** (A01–A04; no device input).
2. **B — device behaviour at default settings** (A05, A06 windows, groups B–F; D2 text input; D3 keys).
3. **G — settings run** (G01–G09 under D4/D5).
4. **Coordinator pixel inspection** of every B and G frame: `migration/evidence/NS07/pixel-inspection-coordinator.md` (including the privacy/redaction check).
5. **F — fixes (only if a case FAILs)**: new candidate build, rerun A gates plus the affected cases and their neighbours in a new run-id.

## Device input rules (lessons from NS03–NS06 and RN07)

- Capture branch/HEAD/index/porcelain and evaluate the gate before writing any evidence.
- Before every tap or gesture: fresh UI XML, confirm the target's bounds, act at their centre, then poll the XML (up to 10 s) for the expected state before capturing. Match text exactly (case-insensitive equality), never by substring.
- No gesture may start within 100 px of a screen edge. Row open/closed is judged by the content's right edge (≥ 240 px left of closed = open; within 10 px = closed). The revealed swipe action is not in the XML: tap it at the computed revealed-strip centre, only when the row is shown open.
- Keys only per D3; text only per D2; settings only per D4.
- Cold launch: `am force-stop dev.translationtest.ns`, then `monkey -p dev.translationtest.ns -c android.intent.category.LAUNCHER 1`; record every relaunch (favorites and filters reset by design).
- `node -e` / `python -c` are blocked in Hermes headless: write helper files. Counts from JSON reporters only. The app bundle is `assets/app/bundle.mjs`.

## Fix policy (target-only, in-scope)

A fix is allowed only for a case that has FAILed, must be the smallest change that makes it pass, and may touch only `migration/nativescript/src/components/*.vue`, `migration/nativescript/src/state/*.ts` and their tests in `migration/nativescript/__tests__/`. No dependency, lockfile, App_Resources, `nativescript.config.ts`, webpack, tsconfig or Vitest config change; no debug routes or test-only product controls. Every fix records the failing case, the diff, the new candidate hash and the rerun evidence. Anything else needs a package amendment from the human.
