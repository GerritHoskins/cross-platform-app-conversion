## Fixed interface

```ts
// types.ts additions
export type ScheduleMode = 'all' | 'favorites';
export interface Selection {
  searchText: string;
  selectedTracks: readonly string[];
  favoriteIds: readonly number[];
  mode: ScheduleMode;
}
export interface SessionGroup { groupTime: string; sessions: Session[] }

// selection.ts
export function selectSessions(sessions: readonly Session[], selection: Selection): Session[];
export function initialSelectedTracks(sessions: readonly Session[]): string[];
export function createInitialSelection(conference: Conference): Selection;
export function sortTracksByName(tracks: readonly Track[]): Track[];

// grouping.ts
export function groupSessions(sessions: readonly Session[]): SessionGroup[];

// favorites.ts
export function addFavorite(ids: readonly number[], sessionId: number): number[];
export function removeFavorite(ids: readonly number[], sessionId: number): number[];
```

The plan's five core functions are `selectSessions`, `groupSessions`, `addFavorite`, `removeFavorite` and C02's `normalizeConference`. The planner adds `initialSelectedTracks`, `createInitialSelection` and `sortTracksByName` here so both targets share the first-load and filter-list behavior instead of re-implementing it. No other exports.

## Behavior (from the contract; cite these lines in code comments)

- `selectSessions`: return the passing sessions **in input order** (no sorting; sorting is `groupSessions`' job), as new array. A session passes when all of these hold:
  - `mode === 'favorites'` implies `favoriteIds` includes `session.id` (IDs not present in `sessions` are ignored);
  - `selectedTracks` is non-empty, and **every** track of the session is in `selectedTracks` (`sessions.ts:192-206`);
  - if `searchText` is truthy, `session.name.toLowerCase().includes(searchText.toLowerCase())`. Do not trim: a single space is truthy and matches names containing a space, exactly like the source.
- `groupSessions`: copy, stable-sort by `startMinutes` (equal times keep input order), then group by `groupTime` in first-occurrence order (`SessionList.vue:269-291`). Each group's `sessions` keeps the sorted order. Empty input gives `[]`.
- `addFavorite`: new array; append `sessionId` only if absent (`sessions.ts:72-76`). `removeFavorite`: new array without any occurrence of `sessionId`; an absent ID gives an equal copy (`sessions.ts:77-79`). Neither mutates its input.
- `initialSelectedTracks`: every track that appears on a session, in first-appearance order (`new Set(sessions.flatMap(s => s.tracks))`, `sessions.ts:124-128`). For the fixture: `Food, Ionic, Tooling, Vue, Design, Services, Workshop, Communication, Navigation, Documentation`.
- `createInitialSelection`: `{ searchText: '', selectedTracks: initialSelectedTracks(conference.sessions), favoriteIds: [], mode: 'all' }`.
- `sortTracksByName`: new array sorted by `a.name.localeCompare(b.name)` (`sessions.ts:187-191`, `allTracksFilter`).
- Every function is pure: no input mutation, no module-level state.
