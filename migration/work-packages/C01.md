## Fixed decisions

- Package name `@migration/core`, version `0.1.0`, `"private": true`, no `"type": "module"` (CommonJS output).
- `"main": "dist/index.js"`, `"types": "dist/index.d.ts"`, `"files": ["dist"]`, and
  `"exports": { ".": { "types": "./dist/index.d.ts", "require": "./dist/index.js", "default": "./dist/index.js" } }`.
- devDependencies, exact versions (no `^`): `typescript` `5.9.3`; `@types/node` at the exact version npm resolves for the current major, recorded in the handoff. No other dependencies.
- `tsconfig.json`: `target` `ES2022`, `module` `node16`, `moduleResolution` `node16` (needed for the `exports` map and package self-reference; without `"type": "module"` it still emits CommonJS), `strict` `true`, `declaration` `true`, `rootDir` `src`, `outDir` `dist`, `include` `["src"]`, `types` `["node"]`.
- `tsconfig.test.json`: extends `./tsconfig.json`, `rootDir` `.`, `outDir` `build-test`, `declaration` `false`, `include` `["test"]`.
- Scripts:
  - `clean`: `node -e "for (const d of ['dist','build-test']) require('fs').rmSync(d,{recursive:true,force:true})"`
  - `build`: `npm run clean && tsc -p tsconfig.json`
  - `test`: `npm run build && tsc -p tsconfig.test.json && node --test build-test/test/`
  - `typecheck`: `npm run build && tsc -p tsconfig.test.json --noEmit` (tests import the built package, so `dist/` must exist first)
- `.gitignore`: `node_modules/`, `dist/`, `build-test/`.
