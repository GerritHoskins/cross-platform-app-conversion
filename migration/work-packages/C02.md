## Fixed interface

`src/types.ts`:

```ts
export interface Session {
  id: number;              // parsed from the data's numeric string id
  name: string;
  timeStart: string;       // display string, unchanged, e.g. "8:00 am"
  timeEnd: string;         // display string, unchanged
  startMinutes: number;    // parseTimeToMinutes(timeStart), always finite after normalization
  endMinutes: number;      // parseTimeToMinutes(timeEnd), always finite after normalization
  location: string;
  description: string;     // '' when missing
  tracks: string[];
  speakerIds: number[];    // unresolved names omitted (contract decision)
  groupTime: string;       // the containing group's `time`, unchanged
}

export interface Track { name: string; icon: string }   // icon = data's icon name; targets map their own icons
export interface Speaker { id: number; name: string }   // other speaker fields are out of scope for slice 1

export interface Conference {
  date: string;            // schedule[0].date
  sessions: Session[];     // data order: groups in order, sessions in order within each group
  tracks: Track[];         // data order
  speakers: Speaker[];     // data order
}
```

`src/time.ts`: `parseTimeToMinutes(time: string): number` and `compareTimes(a: string, b: string): number`, behaviorally identical to `src/utils/time.ts` (same regex, hours 1-12, minutes 0-59, `12:xx am` = 0:xx, malformed returns `Infinity`, `compareTimes` returns 0 when the difference is `NaN`). Copy the logic; do not import from the root project.

## Normalization rules

Source of truth: `sessions.ts:100-121` plus the contract decisions. Where the source is permissive (for example `parseInt`), core is strict and throws, because targets bundle fixed data and bad data should fail loudly at load time.

- Use `schedule[0]` only (as the source does). `raw.schedule` must be a non-empty array; `schedule[0].groups` an array; `schedule[0].date` a string.
- Group: `time` must be a string that `parseTimeToMinutes` accepts; `sessions` an array.
- Session `id`: a string or number matching `/^\d+$/` after `String(...)`, converted with `Number`. Duplicate IDs across the schedule are an error.
- `name`, `location`: required strings (`name` non-empty).
- `timeStart`, `timeEnd`: required strings that `parseTimeToMinutes` accepts (finite). Keep the original strings.
- `tracks`: required array of non-empty strings (an empty array is allowed and recorded in the handoff as an edge case).
- `description`: optional; missing, `null` or `''` becomes `''`; any other non-string is an error.
- `speakerNames`: optional array of strings. Resolve through `speakers[]` by exact name (if two speakers share a name, the later one wins, as with the source's `new Map(...)`). Omit unresolved names. Keep the order of `speakerNames`.
- `speakers[]`: each needs `id` (numeric string or number, as for sessions) and non-empty `name`. Ignore all other fields.
- `tracks[]` (top level): each needs non-empty string `name` and string `icon`.
- Every error is a `ConferenceDataError` whose message starts with its `path`, then states what was expected and what was found, for example `schedule[0].groups[2].sessions[1].timeStart: expected a 12-hour time like "8:00 am", got "25:00"`.
- Pure: never mutate `raw`; return fresh objects and arrays (no shared array references with the input).
