## What E01 is

E01 writes the comparison report for slice 1 (plan row E01, `migration/plans/qwen-work-packages.md`): the same reference behaviour (`migration/reference/contract.md`) was migrated twice, to Expo React Native (RN01–RN07) and to NativeScript-Vue (NS01–NS07), on one shared core (C01–C03). The report compares measured effort, actual results, blockers and unverified items, and recommends the next slice and a lead target. It is a report only: no product, test, config, dependency, checklist or earlier-evidence change, no device or emulator use, no build or install.
