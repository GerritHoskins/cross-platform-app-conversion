## Deliberate core decisions

P02 CD1/CD2/CD3 and their contract sections are cited in the implementation and tests. Sorting is raw UTF-16 code-unit order with numeric ID ties and stable equal pairs, never locale collation. Speaker sessions retain store order and original session objects. Route parsing accepts only canonical positive safe-integer strings; arrays, numeric inputs and final line terminators are malformed. Lookup distinguishes malformed-id from unknown-id and returns the original profile on a hit.

P02's synthetic missingFields probe defaults a missing name to an empty string. C04 deliberately retains C02's stricter non-empty name rule: a missing or empty name throws ConferenceDataError. The fixture contains no nameless speaker. The fixture supplemental optional fields are checked with a present name; the missing-name path is separately asserted. This is the coordinator's explicit core decision, not a failed fixture case. Optional title/about/profilePic accept strings unchanged, default absent/null/empty values to empty strings, and reject all other types at their exact field paths. Profiles do not require valid sessions or tracks.
